# Reading Group Presentation Guide

This is a **suggested template**, not a mandatory format. The priority is an accurate and critical discussion of the work.

## Before presenting

Read the full paper and inspect its cited baselines, experiments, supplementary materials, and code where available. Identify the research question and how the reported evidence answers it. Share the link with participants ahead of time.

## Suggested walkthrough

| Section | Questions to answer |
| --- | --- |
| Problem and motivation | What problem is being solved, and why does it matter? |
| Prior work and gap | Which baselines or prior ideas does the paper build on? |
| Method | What is actually new? Explain the central mechanism with a figure or example. |
| Experimental design | What datasets, comparisons, metrics, and controls are used? |
| Results | Which results support the main claim? Report uncertainty where provided. |
| Limitations | What assumptions, confounders, failure cases, or missing ablations matter? |
| Discussion | What should the community test, reproduce, or pursue next? |

A typical session could allocate **20–30 minutes** to the walkthrough and **20–30 minutes** to questions and discussion. Actual timings are to be set by the organizers.

## Session-notes template

```md
# Paper title

- Paper: <paper URL>
- Presenter: TBA
- Date: TBA

## Main contributions

## Reproducibility and available code

## Slides / notes
```

Do not quote large sections of a paper into repository notes; cite the original paper and summarize in your own words.
