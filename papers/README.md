# Candidate Paper Library

This library is a **paper-only, editable reference index** extracted from [CLU Lab's candidate-paper lists](https://github.com/clulab/nlp-reading-group/tree/master/candidate_papers). It retains the linked reading suggestions while excluding the source group's individual proposer names and discussion notes. Some older URLs may no longer work.

The lists are **not BRAC University session records**. To nominate a paper for the BRAC schedule, open a [paper suggestion issue](https://github.com/SyedNaveedMahmood/bracu-nlp-reading-group/issues/new/choose).
